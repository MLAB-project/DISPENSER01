# DISPENSER01
Smart solder paste dispenser. 

## Introduction
MLAB DISPENSER01 is an open-source solder paste, flux, and other liquid materials dispenser project. This device is built on the Astrometers AMFOC01 hardware, which is equipped with an ARM M0+ processor and a powerful coil driver, ensuring reliable control of the electromagnetic valve.

### Features
- **Dispensing various materials**: Allows for precise and consistent material dispensing.
- **User-friendly configuration**: Users can create and modify profiles for different types of materials and applications.
- **Configuration storage in internal storage**: Configurations can be transferred and modified via USB-C.

## Usage
The DISPENSER01 can be operated using the UI on the OLED display or via an external "wired" controller. A footswitch can also be connected to the dispenser for convenient handling of the device.
